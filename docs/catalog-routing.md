# Каталог и маршруты ALLIN

Главная — полный каталог с поиском: 19 разделов и 169 подкатегорий. На главной видны первые пять подкатегорий каждого раздела (или все, если их меньше); полный список открывается по заголовку в существующей нижней панели. Сетка сохраняет расположение 3 + 2, а на узких экранах — две колонки. Разделы виртуализированы через FlatList; поиск закреплён в заголовке списка, подвал прокручивается вместе с каталогом.

## Основная навигация

| Маршрут | Назначение |
| --- | --- |
| `/(tabs)/services` | Главная вкладка: поиск и все категории с подкатегориями |
| `/(tabs)/favorites` | Вкладка «Избранное»: сохранённые предложения |
| `/(tabs)/orders` | Существующая вкладка «Заказы» |
| `/(tabs)/profile` | Существующая вкладка «Профиль» |
| `/categories` | Совместимая старая ссылка: перенаправляет на главную |
| `/category/[categoryId]` | Подкатегории, поиск внутри раздела, предложения категории |
| `/category/[categoryId]/[subcategoryId]` | Предложения подкатегории и переключение между соседними подкатегориями |
| `/listing/[listingId]` | Информация о предложении, исполнитель, цена, избранное |
| `/search` | Текстовый поиск, категория, максимальная цена, сортировка по цене |
| `/shop/[shopId]` | Сохранённый прежний экран магазина |

`/` и `/categories` перенаправляют в `/(tabs)/services`. Заголовок раздела открывает нижнюю панель со всеми его подкатегориями, не меняя маршрут главной. Панель использует общий `GenericBottomSheet`, раскрывается на 92% высоты и поддерживает прокрутку, закрытие крестиком слева, нажатием на фон и свайпом вниз. После выбора подкатегории панель закрывается и открывается её выдача. Под сеткой расположена кнопка «Перейти в категорию», открывающая `/category/[categoryId]`. Плитки на главной по-прежнему ведут сразу в подкатегорию. Страница категории также доступна по прямой ссылке и из карточки предложения.

Страницы выдачи и карточки открываются в корневом Stack, поверх вкладок. Стандартная кнопка назад возвращает на предыдущий экран. Корневой Stack задаёт вкладки как anchor для прямых ссылок. Удалены прежние группы `main`, `transport` и вложенная группа `services`; все внутренние ссылки на них обновлены.

Поиск принимает `categoryId`, `subcategoryId`, `q`. При смене категории сбрасывается выбранная подкатегория. Несуществующие идентификаторы дают явный экран «не найдено» со ссылкой на каталог; пустая выдача предлагает сбросить фильтры.

## Данные и внешний вид

Иллюстрации `assets/imgs` сжаты без потерь: 243 файла занимают 52,1 МБ вместо 72,7 МБ. Используются 240 WebP и 3 PNG; размеры и все RGBA-пиксели сохранены и проверены. Статические require и манифесты указывают на актуальные расширения. После смены расширений работающему Metro требуется очистка кеша (`npx expo start --clear`).

Состав разделов, названия, аудитория и основные изображения берутся из `assets/imgs/catalog/sources.json`. Статические `require` для Metro собраны в `features/services/utils/catalog-images.ts`. Доставка и переезды, автомойка и другие исключённые пользователем пункты отсутствуют. Пассажирские перевозки исключены; самолёт относится к «Авто → Тюнинг». Мужской и женский уход различаются видимой подписью аудитории и accessibility-label.

Данные локальные и демонстрационные: 169 подкатегорий, 338 предложений. Главная, полная панель, выдача и поиск используют один каталог; ограничение пятью плитками применяется только при отображении главной. Изображения включают подборку Thiings и прежние ресурсы проекта. Реальные объявления, сообщения, оформление заказа и серверное избранное в эту реализацию не входят. Текущий profile-store хранит избранное до перезагрузки приложения.

Новые экраны используют `shared/theme`: светлая и тёмная темы, единая типографика, отступы и радиусы. На узких экранах сетка категорий меняется на две колонки; при крупном системном шрифте лента становится одноколоночной. Изображения имеют зарезервированное место, сердце — отдельную область нажатия 44 × 44.

Каталог уплотнён по сравнению с первой версией: базовая высота плитки 96 pt вместо 140, подпись 14 pt, заголовок раздела 20 pt вместо 24, интервал между разделами 24 pt вместо 32. Эти плитки используются и на главной, и в панели подкатегорий. Высота остаётся минимальной, а не фиксированной: длинные названия и системное увеличение текста могут расширять плитки. Поиск использует общий размер 48 pt. Компактная сетка проверена в Chrome на 390/320 px в обеих темах, включая поиск и переходы в категорию и подкатегорию; ошибок выполнения нет.

## Проверка

После подключения полной подборки проверены пять тестов каталога: сохранность всех 19 разделов и 169 подкатегорий, наличие основных изображений, уникальность маршрутов, поиск и фильтры. В Chrome проверены все 20 заголовков, максимум пять плиток в разделе главной, все 15 подкатегорий «Авто» в панели, переход к «Тюнингу», возврат, повторное открытие и закрытие панели, 320/390 px, светлая и тёмная темы. Ошибок выполнения нет. Нативный запуск и Dynamic Type на устройстве не проверялись. Общие lint/typecheck сохраняют несвязанные ошибки, затронутые файлы ошибок не добавляют.

### Предыдущие проверки до подключения полной подборки

После переноса каталога на главную проверены все шесть разделов, отсутствие ленты рекомендаций, закреплённый поиск при прокрутке, переходы в категорию и напрямую в подкатегорию, возврат назад, ширины 390/320 px и тёмная тема. Ошибок выполнения в браузерном прогоне нет; новые файлы проходят ESLint, общий TypeScript сохраняет 88 прежних ошибок.

Чистая логика каталога проверяется командой `node tests/catalog.test.cjs`: целостность маршрутов, поиск с ё/е и несколькими словами, совмещение фильтров и сортировка без изменения исходных данных.

Для панели подкатегорий проверены открытие без смены маршрута, полный список, закрытие крестиком, перетаскиванием и нажатием на фон, повторное открытие другой категории, переход после выбора, прокрутка на 320 px и тёмная тема. Проверка выполнена в Chrome; нативные жесты на физическом устройстве не проверялись. Изменённые компоненты проходят ESLint; TypeScript сохраняет 88 прежних ошибок.

Результат проверки 04.11.2026:

- Все четыре теста каталога прошли.
- В Chrome на ширине 390 px проверены переходы по иерархии, возврат назад, добавление и удаление избранного, поиск по словам, пустая выдача и сброс фильтров. Финальный прогон не содержит ошибок выполнения и сообщений `console.error`.
- Просмотрены скриншоты сетки на 320 px, светлой и тёмной темы. Проверка на физическом iOS/Android-устройстве не выполнялась.
- `npm.cmd run typecheck`: 88 оставшихся ошибок против 125 до изменения. В новых маршрутах и экранах каталога ошибок нет. Прежние проблемы включают несовместимые props старого Text, отсутствующие зависимости и ссылку настроек на отсутствующий change-password.
- `npm.cmd run lint` и повторный ESLint без кэша: 56 ошибок, 23 предупреждения против 57 ошибок и 24 предупреждений до изменения. В новых компонентах каталога ошибок нет.
- Ограничение локального веб-сервера: прямой HTTP-переход на `/search` вызывает ошибку SSR Metro `Requiring unknown module "867"`; повторный запуск с `--clear` её не устранил. Переход в поиск внутри приложения и сам поиск работают. Прямые веб-ссылки нельзя считать полностью проверенными; конфигурация зависимостей и сборщика в этой задаче не изменялась.
