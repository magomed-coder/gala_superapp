# Экран профиля

Профиль оформлен по референсу `5.jfif`: светло-серый фон, компактная карточка аккаунта, тёмный акцентный блок и округлённые группы меню с тонкими разделителями. Маршрут остаётся `/(tabs)/profile`.

По уточнению пользователя у всех корневых экранов вкладок убраны верхние шапки. Профиль начинается с карточки аккаунта, поиск — с поискового поля, заказы — с фильтров, избранное — со счётчика и предложений. Верхняя безопасная область сохраняется. У вложенных страниц остаётся навигация назад.

Карточка читает имя, email и аватар из существующего `useAuthStore`. При отсутствии аккаунта предлагает вход; при ошибке изображения показывает инициалы. Авторизованный пользователь переходит к прежнему экрану редактирования. Сам редактор профиля в этой задаче не перерабатывался.

Тёмный блок открывает «Избранное». Основные группы ведут к настройкам, заказам, способам оплаты, адресам, безопасности, уведомлениям, поддержке и информации о приложении. Переключатель темы использует существующий `theme-mode.store` с сохранением выбора. Подтверждённый выход вызывает `logout()` текущей демонстрационной сессии.

Для фона добавлен семантический токен `colors.background.grouped` в обе темы. `ProfileMenuGroup` расположен в `features/profile/components/`; нового общего слоя UI или зависимостей нет.

## Проверка по emil-design-eng

| Before | After | Why |
| --- | --- | --- |
| Большой блок с тестовым Иваном Петровым и статусами Premium/Gold | Компактная строка реального состояния аккаунта | Соответствие референсу и данным текущей сессии |
| Один длинный список | Три группы с округлением и разделителями | Связанные действия проще просматривать |
| Цвета заданы внутри экрана | Общие токены и светлая/тёмная темы | Единое оформление с каталогом |
| На 320 px кнопка баннера оставляла мало места тексту | Компактная стрелка при малой ширине или крупном шрифте | Текст остаётся читаемым без обрезания |

Проверки выполняются в мобильном viewport Chrome 390 и 320 px; это не заменяет проверку на физическом iOS/Android-устройстве. Внешний аватар демо-аккаунта в автоматическом прогоне заменяется локальным изображением, чтобы не зависеть от стороннего сервиса.

Финальный прогон прошёл без ошибок выполнения: светлая/тёмная тема, узкая ширина, избранное, поиск, демо-вход, отображение аккаунта, переход к редактированию, отмена и подтверждение выхода. Отдельно проверены все четыре корневые вкладки после удаления шапок.

Общий TypeScript сохраняет 88 прежних ошибок. В изменённых файлах ошибок нет; ESLint этих файлов проходит. Общий ESLint: 56 прежних ошибок и 17 предупреждений (до изменения — 56 и 23). Неисправности старых дочерних экранов и серверная интеграция остаются отдельной задачей.
